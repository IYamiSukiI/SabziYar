
سبزی‌یار — پروژه اندروید نسخه اول

این پوشه یک پروژه Android Studio است. برای ساخت فایل APK:
1. پروژه را در Android Studio باز کنید.
2. Gradle Sync را اجرا کنید.
3. از منوی Build > Build APK(s) فایل APK را بسازید.

نسخه فعلی مخصوص فروش بسته‌ای سبزی طراحی شده:
- بسته خوردن
- بسته خورشی
- بسته ماهی
- ثبت مشتری
- ثبت تعداد بسته برای هر مشتری
- مشاهده سفارش‌ها
- صدور وضعیت فاکتور
- گزارش تعداد بسته‌های امروز
- ذخیره اطلاعات روی خود گوشی
